# 모바일 견적 상태별 수정 제한 정책

## 적용 화면

- `src/views/EstimateDetail.vue`: 견적 상세, 샤시 추가 버튼, 샤시 카드 진입
- `src/views/SashNew.vue`: 샤시 신규/수정 화면, 저장/견적추가 버튼, 직접 URL 접근 방어

## 상태 기준

| 상태 코드 | 의미 | 정책 |
|---|---|---|
| 없음/공백/조회 실패 | 상태 미확인 | 편집 불가. fail-closed |
| `0` | 품목 없음 | 헤더 API로 확인된 경우 첫 품목 추가 가능. 기존 row 수정 권한으로는 사용하지 않음 |
| `10` | 견적 | 샤시 추가/수정 가능 |
| `20` 이상 | 장바구니 이상 | 기본 수정 불가 |
| `50` 이상 | 주문/수주 이후 | 조회 전용 |

편집 가능 여부는 보수적으로 판단한다. 기존 품목 수정은 확정된 상태 코드가 `10`인 경우만 가능하며, `20`, `50`, `65`, `80`, `90`, 비정상 문자열, 공백, API 실패는 모두 저장 불가다. `50` 이상은 조회 전용 안내를 우선 표시한다. 단, legacy `selectItgEstiHeader`는 품목이 없는 신규 헤더의 `stCd`를 `0`으로 내려주므로, 헤더 API에서 확인된 `0`은 첫 품목 추가/신규 샤시 작성에 한해 허용한다.

## EstimateDetail 정책

견적 상세의 샤시 추가 가능 여부는 헤더 상태를 기준으로 한다.

- 헤더 `stCd`/`igStCd`가 `10`이면 `+ 샤시` 또는 `+ 품목 추가` 버튼을 노출한다.
- 헤더 `stCd`가 `0`이면 아직 품목이 없는 견적 헤더로 보고 `+ 품목 추가` 버튼을 노출한다.
- 헤더 상태가 `20` 이상이면 `+ 샤시` 버튼을 숨기고 수정 불가 안내를 표시한다.
- 헤더 상태가 `50` 이상이면 조회 전용 안내를 표시한다.
- 헤더 상태가 없거나 조회 실패하면 버튼을 노출하지 않는다.

샤시 카드 수정 가능 여부는 헤더 상태와 개별 샤시 상태를 함께 본다.

- 헤더가 `20` 이상이면 모든 샤시 카드는 조회 전용으로 진입한다.
- 헤더가 편집 가능하면 개별 샤시 `stCd`/`igStCd`를 기준으로 판단한다.
- 개별 샤시 상태가 `10`이면 수정 가능하다.
- 개별 샤시 상태가 `20` 이상이면 `readonly=Y`와 상태 코드를 넘겨 수정 화면을 조회 전용으로 연다.
- 개별 샤시 상태가 없고 헤더 상태도 확인되지 않으면 조회 전용으로 연다.

따라서 일부 항목만 상태가 다른 경우에도 헤더가 편집 가능하면 상태 `10`인 샤시는 수정 가능하고, 상태 `20` 이상이거나 미확인인 샤시는 조회 전용이다.

## SashNew 정책

샤시 작성 화면은 직접 URL 접근도 방어한다.

- URL query의 `stCd`는 최종 권한 판단에 신뢰하지 않는다. 화면 전환 중 임시 표시 힌트로만 사용할 수 있다.
- 저장 가능 여부는 헤더 API와 샤시 상세 API에서 확인된 상태만 근거로 판단한다.
- 헤더 API 성공 시 `header.stCd`/`header.igStCd`를 헤더 상태로 사용한다.
- 헤더 API 실패, 상태 없음, 비정상 상태는 모두 `UNKNOWN`으로 보고 저장 불가 처리한다.
- 신규 저장은 헤더 상태가 `10`이거나, 헤더 API에서 확인된 품목 없음 상태 `0`일 때만 가능하다.
- 수정 저장은 헤더 상태가 `10`이고, 샤시 상세 row 상태도 `10`이거나 row 상태가 없어 헤더 상태로 대체 가능한 경우에만 가능하다.
- 헤더 상태가 `20` 이상이면 row 상태가 `10`이어도 전체 조회 전용으로 본다.
- 상세 row 상태가 `20` 이상이면 헤더 상태가 `10`이어도 해당 샤시는 조회 전용이다.
- 저장 불가 상태에서는 저장/견적추가 버튼을 숨기고 저장 함수도 즉시 차단한다.
- 상태가 `50` 이상이면 조회 전용 안내를 표시한다.

저장 차단 메시지:

```text
현재 수정할 수 없는 상태입니다
```

## 테스트 기준

- 상태 `10`: 견적 상세에서 추가 가능, 샤시 수정 가능
- 상태 `20`: 견적 상세에서 추가 불가, 샤시 수정 화면은 저장 불가
- 상태 `50`: 조회 전용 안내 표시, 저장 불가
- 직접 URL 접근: `SashNew.vue`가 헤더/상세 상태를 조회해 저장을 차단

## 주의사항

- 웹 `SashForm.vue` 기준과 맞추기 위해 `SashForm2.vue`는 정책 기준에 포함하지 않는다.
- 상태 정책은 프론트 UX 방어이며, 백엔드 저장 API도 상태별 저장 가능 여부를 별도로 검증하는 것이 최종 안전장치다.
